# Constitution: independent Part 1B
1. Specification and student approval precede implementation and final benchmark freeze.
2. The independent harness never trusts or rewrites provider outputs.
3. Preserve every failure, actual repair and re-evaluation; never fabricate logs.
4. Minimize exposure: no execution, no local source persistence, explicit transfer consent.
5. Human decisions are recorded by the reviewer and never made automatically.
6. A live Groq 100% result cannot be claimed from offline or mocked tests.
7. Original Part 1B remains separate and is not an evidence source for this project.
